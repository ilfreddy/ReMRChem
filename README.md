# ReMRChem

Welcome to **ReMRChem**! This repository hosts a Python-based implementation for performing highly accurate relativistic quantum chemistry calculations within the MultiWavelets framework.

## Scope of the Code

ReMRChem is designed to perform precise relativistic electronic structure calculations using Multiwavelets. It leverages the mathematical properties of multiwavelets to achieve arbitrary precision, avoiding the common pitfalls of traditional basis sets (like Gaussian-type orbitals). Currently, the code supports calculations for 1- or 2-electron systems by taking advantage of time-reversal symmetry. You can perform Self-Consistent Field (SCF) procedures using either the standard Dirac Hamiltonian or the Dirac Squared Hamiltonian.

## Theory and Motivation

In modern quantum chemistry, dealing with heavy elements requires a fully relativistic treatment to accurately describe scalar relativistic effects and spin-orbit coupling. The 4-component Dirac equation provides the most rigorous framework for this. However, traditional basis sets often struggle to represent the complicated nodal structures and cusps of the wavefunctions appropriately, especially near the nucleus. 

Multiwavelets offer a powerful alternative framework. By using a multiresolution analysis, multiwavelets can adaptively refine the numerical grid, meaning they guarantee a predefined precision for the computed wavefunctions and energies. ReMRChem (Relativistic MultiResolution Chemistry) is built on top of the `vampyr` library to bring these advantages to relativistic calculations, paving the way for benchmark-quality results without being constrained by basis set truncation errors.

## Repository Structure

Here is a quick overview of what you'll find in the repository:

### Core Scripts
- **`test.py`**: The main executable script used to run calculations.
- **`one_electron.py` & `two_electron.py`**: Handle the physics and SCF routines for 1-electron and 2-electron systems, respectively. These are the main point of the implementation.
- **`starting_guess.py`**: Generates the initial guess wavefunctions to kickstart the SCF procedure.
- **`test_operators.py`**: A dedicated suite for testing and verifying the implemented numerical operators. Not relevant for the user.
- **`scf.py`**: Contains some subroutines which did not make it to the full code 

### **`orbital4c/`** (4-Component Orbitals Module)
This directory contains the underlying machinery for the relativistic components:
- **`orbital.py`**: Defines the data structures and methods for 4-component Dirac spinors.
- **`complex_fcn.py`**: Handles operations on complex functions represented within the multiwavelet basis.
- **`nuclear_potential.py`**: Routines to compute accurate nuclear potentials (e.g. finite-nucleus models).
- **`operators.py`**: Constructs and defines relativistic operators (kinetic energy, potential operators, etc.).
- **`param_V.txt`**: Parameters related to potential evaluations.
- **`r3m.py`**: R3M potential and mathematical routines. Did not make it in the final code

### Data & Examples
- **`Z.txt`** & **`Half_Charge_Radius.txt`**: Data files containing atomic numbers and standard half-charge radii for elements, mainly used when constructing accurate finite nuclear potentials.
- **`input_example.txt`**: A ready-to-use example input configuration file to help you format your own calculations.
- **`outputs/outputinput_example.txt`**: The expected output generated by running the provided input example.

## How to Run the Calculations

To run ReMRChem, you must have the `vampyr` library installed in your Python environment. You can install all necessary dependencies manually or via your preferred virtual environment setup.

1. **Prepare your input:**
   Create a configuration text file specifying the parameters of your calculation. We highly recommend using the provided `input_example.txt` as a template.

2. **Run the code:**
   Execute the calculation from the main repository folder directly in your terminal by passing the input file as an argument:
   ```bash
   python test.py input_example.txt
   ```

3. **Check the output:**
   The output of the SCF procedure will be printed live in your terminal. Once convergence is achieved for the 1- or 2-electron systems, the code computes and displays the expectation values using both the standard Dirac and Dirac squared Hamiltonians. You can compare your results against `outputs/outputinput_example.txt` to seamlessly guide your verification.

Enjoy running your highly-accurate relativistic calculations!
